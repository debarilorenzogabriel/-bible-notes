# -bible-notes
Repository per il codice sorgente di Bible Notes, un’app Android di studio biblico pensata per prendere appunti in modo semplice e organizzato. Contiene l’app web (HTML/CSS/JS) integrata in un progetto Capacitor, con funzionalità di editor di note, gestione etichette, riferimenti biblici cliccabili e apertura dei versetti in JW Library o su jw.org.
